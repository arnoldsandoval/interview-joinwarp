# @repo/icons

This package contains the icons used in our calendar app. This icon package is derived from a subset of the [Phosphor icon family](https://phosphoricons.com/).

## Usage

### 1. **Install `@repo/icons`:**

```
pnpm install --workspace @repo/icons
```

### 2. **Use `@repo/icons`:**

```ts
import { Settings } from "@repo/icons"; // 👈 Import the icon
import { Button } from "@repo/ui";

const MyComponent = () => {
    return (
        <Button>
            <Settings /> Knobs and levers
        </Button>
    )
}
```

## Adding an icon

### 1. Export SVG(s):

- Save to `src`.
- **Note:** Most icons come directly from [Phosphor icons](https://phosphoricons.com/?weight=%22regular%22&size=20) and should be exported at a size of 20px. Please ensure you are exporting the SVG version, NOT the Raw SVG version. Unless otherwise stated, use the Regular style.

### 2. Optimize and Generate React Components with SVGO and SVGR:

- Run `pnpm build`.

### 3. Update icon docs

- Add the new icon to our @repo/ui docs, found in `/packages/ui/src/docs/Icons.stories.tsx`

### 4. Commit the new svg

- Commit and push the docs and icon assets in `src`.

## Directory structure

### `src`

Contains the raw assets exported from Figma before any processing.

```
src/
  ├── icon1.svg
  ├── icon2.svg
  ├── ...
```

### `dist`

Contains the final build artifacts, which have been optimized (via SVGO) and converted in to React components generated by SVGR.

```
dist/
  ├── Icon1.svg
  ├── Icon1.tsx
  ├── Icon2.svg
  ├── Icon2.tsx
  └── ...
```
